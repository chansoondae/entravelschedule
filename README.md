# 앙트레블 강연장 주말 대여 가능 시간

네이버 예약에 등록된 **앙트레블** 강연장의 예약 현황을 조회해서, 주말에 2시간 단위로 빌릴 수 있는 시간을 보여주는 도구입니다.

- 네이버 지도: https://map.naver.com/p/entry/place/1260927975
- 네이버 예약: https://m.booking.naver.com/booking/10/bizes/1056959/items/8046643

> ⚠️ 네이버는 예약 현황 조회용 공개 API를 제공하지 않습니다. 이 프로젝트는 네이버 예약 웹페이지가 내부적으로 쓰는 비공식 GraphQL API(`m.booking.naver.com/graphql`)를 사용하므로, 네이버 측 변경 시 동작하지 않을 수 있습니다. 개인적인 확인 용도로만, 과도한 호출 없이 사용하세요.

## 구성

```
navermap/
└── web/                       # Next.js 웹앱 (모바일 대응)
    ├── lib/naver.ts           # 네이버 예약 GraphQL 호출 + 칸 상태 판정
    ├── app/api/schedule/      # 서버 API: GET /api/schedule?start=YYYY-MM-DD&days=N
    ├── app/page.tsx           # 화면 + 대여 가능 시간 계산
    ├── app/layout.tsx
    └── app/globals.css
```

## 웹앱 (web/)

### 실행

```bash
cd web
npm install
npm run dev          # http://localhost:3000
```

운영 모드로 실행하려면:

```bash
npm run build && npm start
```

같은 와이파이에 연결된 휴대폰에서는 `http://<이 컴퓨터의 IP>:3000`으로 접속할 수 있습니다.

### 대여 가능 판정 규칙

| 조건 | 값 | 설정 위치 (`web/app/page.tsx`) |
|---|---|---|
| 요일 | 토·일만 | `rows` 계산부 |
| 시간대 | 10:00–20:00 | `OPEN_HOUR`, `CLOSE_HOUR` |
| 대여 단위 | 2시간 | `RENT_HOURS` |
| 기존 예약·운영안함과의 간격 | 앞뒤 1시간 | `BUFFER_HOURS` |
| 조회 기간 | 오늘 ~ 2026-12-31 | `END_DATE` |

h시에 시작하는 2시간 대여는 아래 조건을 **모두** 만족해야 대여 가능으로 표시됩니다.

1. h시, h+1시가 모두 비어 있음
2. h−1시, h+2시에 예약됨·운영안함이 없음 (10시 이전·20시 이후 칸도 실제 상태로 판단)
3. 오늘이면 이미 지난 시각에는 시작할 수 없음

### 화면

- **가장 빠른 대여 가능일**: 맨 위 카드에 보여주고, 네이버 예약으로 가는 버튼이 함께 있음
- **필터**: 전체 / 가능한 날만
- **주말 카드**: 토·일 10칸 타임라인 + 대여 가능 시간 칩
  - 🟩 대여 가능 · 연한 초록 = 비었지만 간격 부족 · 🟥 예약됨 · 빗금 = 운영안함
  - 연속 구간은 합쳐서 표시 (예: `10:00–14:00 중 2시간` = 10~12시 사이 아무 때나 시작)
- 다크모드 자동 지원, 넓은 화면(960px 이상)에서는 2열 배치
- 다른 앱에 갔다가 5분 넘게 지나서 돌아오면 자동 새로고침

### 서버 API

```
GET /api/schedule?start=2026-11-01&days=30
```

- `days`: 1~120
- 응답: `{ slots: [{ date, hour, status }], fetchedAt }`
- `status`: `free`(비어있음) · `booked`(예약됨) · `closed`(운영안함)

브라우저에서 네이버 API를 직접 부르면 CORS에 막히기 때문에, Next.js 서버가 대신 호출합니다.

## 참고

- **운영안함**은 업체가 시간을 막아둔 상태입니다. 네이버 외 채널(전화 등)로 받은 예약일 수 있습니다.
- 이 업체는 24시간 슬롯을 열어두고 있어서, 새벽 시간도 비어 있음으로 나옵니다.
- **TypeScript는 5.x로 고정해야 합니다.** TypeScript 7에서는 Next.js 15가 tsconfig의 경로 별칭(`@/...`)을 읽지 못해 빌드가 실패합니다.
- 해외 서버(예: Vercel)에 배포하면 네이버가 요청을 차단할 수 있으니, 배포 후 실제로 동작하는지 확인하세요.
